# 🌙 Twilight Quiz Bot

Telegram-бот для викторины по книге «Сумерки» Стефани Майер. Проверь, насколько хорошо ты знаешь первую книгу серии!

## Возможности

- 🎮 **Квиз с 3 уровнями сложности**: легко, средне, сложно
- 📊 **Статистика**: отслеживание результатов по каждой игре и по сложности
- 📖 **55 вопросов** по книге «Сумерки» (21 лёгкий, 22 средних, 12 сложных)
- 💾 **SQLite**: все результаты сохраняются в локальной базе данных
- 🔒 **Безопасность**: токен хранится только в `.env`, состояние игры изолировано для каждого пользователя

## Предварительные требования

- **Node.js 20+** (проверить: `node --version`)
- **npm** (поставляется вместе с Node.js)

### Как установить Node.js 20+

1. Перейди на [nodejs.org](https://nodejs.org/)
2. Скачай LTS-версию (Long Term Support) для своей операционной системы
3. Запусти установщик и следуй инструкциям
4. Открой терминал и проверь установку:
   ```bash
   node --version
   npm --version
   ```

## Установка и запуск

### 1. Создание папки проекта

Создай папку для проекта (если ещё не создана):

```bash
mkdir twilight-quiz-bot
cd twilight-quiz-bot
```

### 2. Установка зависимостей

Установи все необходимые пакеты:

```bash
npm install
```

Это установит:
- **grammy** — фреймворк для Telegram Bot API
- **better-sqlite3** — драйвер SQLite
- **dotenv** — загрузка переменных окружения из `.env`

### 3. Создание .env файла

Скопируй пример файла окружения:

```bash
cp .env.example .env
```

Или создай файл `.env` вручную в корне проекта.

### 4. Получение Bot Token от BotFather

1. Открой Telegram и найди [@BotFather](https://t.me/BotFather)
2. Отправь команду `/newbot`
3. Следуй инструкциям: введи имя бота и username (должен оканчиваться на `bot`)
4. BotFather пришлёт тебе **token** вида `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`

### 5. Вставка Bot Token

Открой файл `.env` и вставь полученный токен:

```
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
```

> ⚠️ **Никогда не публикуй и не коммить файл `.env`!** Он уже добавлен в `.gitignore`.

### 6. Запуск бота

```bash
npm start
```

Ты увидишь сообщение: `🌙 Twilight Quiz Bot запущен...`

Теперь открой своего бота в Telegram и отправь `/start`.

### 7. Остановка бота

Нажми **Ctrl+C** в терминале, где запущен бот.

### 8. Режим разработки (с автоперезапуском)

```bash
npm run dev
```

Бот будет автоматически перезапускаться при изменении файлов (Node.js `--watch`).

### 9. Где находится SQLite база

База данных хранится в файле:

```
data/quiz.db
```

Этот файл создаётся автоматически при первом запуске. Он **не коммитится** в git (указан в `.gitignore`).

Для просмотра содержимого можно использовать:
- [DB Browser for SQLite](https://sqlitebrowser.org/)
- Командную строку: `sqlite3 data/quiz.db`

### 10. Как добавить новые вопросы

Открой файл `src/questions.js`. Каждый вопрос — это объект:

```javascript
{
  id: 56,
  question: "Текст вопроса?",
  options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
  correctAnswer: 0,       // индекс правильного ответа (0-3)
  explanation: "Объяснение правильного ответа.",
  difficulty: "easy"      // "easy", "medium" или "hard"
}
```

Добавь новый объект в массив `questions` и сохрани файл. Бот автоматически подхватит новые вопросы при перезапуске.

## Структура проекта

```
twilight-quiz-bot/
├── src/
│   ├── bot.js              — Точка входа, инициализация бота
│   ├── config.js           — Загрузка конфигурации из .env
│   ├── database.js         — Работа с SQLite (создание таблиц, запросы)
│   ├── questions.js        — 55 вопросов по книге «Сумерки»
│   ├── keyboards.js        — Генерация inline-клавиатур
│   └── handlers/
│       ├── start.js        — Обработчик /start и главное меню
│       ├── quiz.js         — Логика квиза: вопросы, ответы, результаты
│       └── stats.js        — Отображение статистики пользователя
├── data/
│   └── .gitkeep            — Пустой файл для сохранения директории в git
├── .env                    — Файл с токеном (не коммитить!)
├── .env.example            — Пример .env файла
├── .gitignore              — Исключения для git
├── package.json            — Зависимости и скрипты
└── README.md               — Эта инструкция
```
